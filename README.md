# VNACHALE — прототип нового пользовательского пути

Демонстрационный прототип витрины [vnachale.shop](https://vnachale.shop). **Это не боевой сайт.**

**Открыть:** https://whsmotilek.github.io/vnachale-prototip/

## Как устроено

Весь прототип — один файл `index.html`. Никакой сборки: открывается двойным кликом.
Фирменный шрифт (`DECO` / `Vnachale-Regular`) и логотипы вшиты в файл,
фотографии товаров подгружаются с Tilda CDN.

Роутинг — по хешу: `#/`, `#/catalog`, `#/p/<id>`, `#/preorder`, `#/about`, `#/info`.

Данные о товарах лежат в константе `PRODUCTS` в начале скрипта: 13 моделей,
27 расцветок, настоящие названия, цены и фотографии с боевого сайта.

## Что показывает

**Главная** — бегущая строка, слайдер-событие со стрелками и точками,
слайдер категорий, авто-карусель товаров в наличии, баннер предзаказа,
образы, полоса доверия, манифест, подвал с полной навигацией.

**Каталог** — без баннера, товары с первого экрана; категории, фильтр
по размеру, сортировка, покупка прямо из плитки.

**Карточка товара** — переключатель цвета, размерная сетка рядом с выбором
размера, оплата частями под кнопкой, раскрывающиеся блоки, комплект «с этим носят».

**Предзаказ** — отдельная страница со сроком поступления.

## Главное отличие от боевого сайта

27 карточек сведены в 13 товаров: расцветки одной модели переключаются
внутри карточки, а не лежат отдельными позициями с одинаковым названием.

## Чего не хватает

Рост и размер модели с фотографий не вынесены отдельной строкой под кнопку.
Для части товаров эти данные уже есть мелким шрифтом на размерных карточках.
